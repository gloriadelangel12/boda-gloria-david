# Invitación web · David & Gloria (31 · Julio · 2027)

## Cómo ejecutarla
1. Abre la carpeta `invitacion_boda_web` en Visual Studio Code.
2. Clic derecho en `index.html` → **Open with Live Server** (o abre el archivo en el navegador).
3. Ya no necesita internet para las tipografías: todas están dentro de `assets/fonts`.

## Tipografías
- **Invitación:** solo dos familias → Cormorant Garamond (texto) y Pinyon Script (nombres y títulos).
- **Portada (sobre cerrado):** conserva sus fuentes originales → Playfair Display y Montserrat.

## Colores y espacios (en `styles.css`, bloque `:root`)
- `--gold`, `--gold-soft`, `--gold-deep`: acento dorado (líneas, adornos y bordes de botones).
- `--sec`: espacio uniforme alrededor de los divisores ornamentales entre secciones.

## Imágenes
Todas las imágenes que usa el sitio están en formato **WebP** (de ~5.8 MB a ~1.4 MB).
`preview-boda.jpg` se queda en JPG a propósito: WhatsApp/Facebook leen mejor ese formato en la vista previa del enlace.
`dg.png` y `sda roja.png` no se usan en el sitio; puedes borrarlas si quieres.

`index.html`, `styles.css`, `fonts.css`, `README.md` y las imágenes de `assets` (PNG → WebP). `script.js` queda intacto.
